## Automated checks and limits

Eleven local Node tests pass, including native HTTPS trust rejection/acceptance, untrimmed
password preservation, complete-body timing, fixture cardinality, wrong clock/nonempty target,
partial checkpoints, saved-target identity, report privacy and strict 300 ms rejection. A fake
measurement deliberately includes a 503 and 300 ms sample: both stay in the report and fail
acceptance. Concurrent loading tests distinguish eight different in-flight writes from retries.

The five secret-scanner tests and tracked-file scan pass. An initial test expectation incorrectly
counted concurrent in-flight writes as one; it was corrected in `b247adf`, without changing the
runtime or its measured results. Windows checkpoint replacement has a bounded local-file retry
for transient sharing violations; HTTP mutations are never retried.

completed successfully: unit/native TLS tests, secret checks, isolated demo, full C-07 measurement
